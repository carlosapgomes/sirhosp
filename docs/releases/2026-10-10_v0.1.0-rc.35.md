- **BREAKING**: `GET /statistics/export/` serve
  `estatisticas-diarias-{data}-r{N}.zip` com um XLSX por setor, em vez do
  workbook único. Stem preservado, extensão `.zip`. A equipe de estatísticas
  solicitou o formato; filenames carregam data + setor (risco aceito).
- Migration `0006`: `StatisticsExportLog.file_count` (backfill `1` nas linhas
  legadas). Migration `0007`: somente `help_text` (sem efeito de schema).
  `migrate --noinput` no upgrade **não** é no-op desta vez.
- Rollback code-only continua seguro: coluna extra `file_count` é ignorada
  pelo código antigo; sem restauração de banco para rollback de imagem.
- Tooling de verificação (`scripts/verify_portal.py`, skill MCP) é dev-only
  e **não** vai para o hospital; nenhum secret novo, nenhuma env nova.
