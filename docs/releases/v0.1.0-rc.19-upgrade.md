# SIRHOSP v0.1.0-rc.19 — Correção do comentário de template vazado no badge (hotfix TCF)

## Status do artefato

Este é o runbook de pré-publicação da candidata `v0.1.0-rc.19`. Ele somente se
torna um asset operacional válido quando anexado, antes da publicação, à
release GitHub imutável da mesma tag e quando a imagem exata existir no GHCR.

O upgrade parte de `v0.1.0-rc.18` (em produção desde 2026-09-02). Esta release
corrige um defeito cosmético introduzido na RC18: o fragmento
`templates/includes/topbar_sync.html` usava um comentário **multi-linha**
`{# ... #}` — sintaxe que em Django só é comentário em linha única — e o
texto literal aparecia no cabeçalho de **todas as páginas autenticadas** e em
cada resposta do endpoint `/atualizacao-censo/`.

A correção converte o comentário para o bloco `{% comment %}...{%
endcomment %}` e adiciona teste de regressão cobrindo as duas superfícies
(página do shell e fragmento do endpoint): nenhuma delas pode conter `{#`,
`{% comment` nem o texto do comentário.

**Diff de produção: 1 template + 1 arquivo de testes.** Sem migration (prova:
zero commits em `**/migrations/` no intervalo), sem dependências, sem
catálogo, sem comando novo, sem mudança em código Python — o comportamento de
workers, orquestrador, health check e regras de negócio é byte-a-byte idêntico
ao da RC18.

**Canário §6.1.4 não aplicável (justificativa documentada):** aquele
procedimento destina-se ao rollout do reconhecimento de atendimentos e a
mudanças que tocam a camada de ingestão. Esta release é exclusivamente da
camada `web` (comentário de template); o código executado pelos workers é
idêntico ao validado pelo canário da RC18 há horas. O deploy segue direto
para a Fase B (drenagem, backup, swap), mantendo todos os demais critérios do
runbook da RC18.
