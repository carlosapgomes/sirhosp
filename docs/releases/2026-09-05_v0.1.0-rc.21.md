## Fase A — canário §6.1.4: ABORTADO (defeito de sequência do runbook)

- Override `compose.canario.yml` atualizado (base = compose em uso,
  imagem rc.21); `config --quiet` OK; `WORKER_CANARIO` subido.
- Crash imediato e repetido: `ProgrammingError: column
  patients_admission.merged_into_id does not exist` — o código rc.21

  runbook previa migrate somente na Fase B. **O canário de uma release

- Decisão do operador: **Fase B direta** (opção 2), registrada aqui.
